# K9Kuts.

A polished demo website for a local dog groomer.

## Includes
- Warm, modern landing page
- Grooming services section
- Dog photo gallery
- Testimonials area
- Booking form
- On-page booking confirmation flow
- Mobile-friendly layout
- Pitch copy for presenting the site helpfully to groomers

## Notes
This version is static and demo-ready.
